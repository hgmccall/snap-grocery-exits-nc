# Access-impact score and risk x impact ranking (validation 2019-2021, report only)

Generated by `src/model/08_impact_score.py`. Inputs are all known on Jan 1 of t; the definition and weights were fixed before any result was looked at. The test file is not read.

**impact = 0.50 x rank(distance to nearest other SNAP grocery on Jan 1) + 0.25 x rank(tract % SNAP households) + 0.25 x rank(tract % households with no vehicle)**, each rank a percentile against the pooled 2012-2021 store-year reference (inputs only), so impact lies in (0, 1]. **priority = predicted exit probability x impact.** Rank tables are in `docs/impact_reference.json` for the app.

Jan-1 distance (`dist_other_grocery_jan1_mi`, built in `05d_context_columns.py`): available for 21,330 store-years 2012-2021 (0 without usable coordinates get distance rank 0.5). Validity check against the exit-time gap measure (outcome-side, used only here): Spearman correlation between Jan-1 distance and distance at the exit date among validation exits = 0.99; 100% of validation 'gap exits' (> 1 mile at exit) already had no other grocery within a mile on Jan 1.

Gap exits in validation: 44 of 225 exits (20%).
